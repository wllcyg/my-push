# 智能云平台故障排查与错误码字典 (v3.2)

> **文档维护**：基础设施运维部 (Infra DevOps Team)  
> **更新时间**：2026年07月20日  

---

## 一、 系统架构关键参数配置

* **主模型接入**：Qwen-Max (版本号 `qwen3.6-plus`)，请求超时时间设置为 `30000ms`。
* **向量检索索引**：PostgreSQL `pgvector` HNSW 索引（参数 `m=16, ef_construction=64`），维度指定为 `1024`。
* **全文检索拓展**：PostgreSQL 启用 `pg_trgm` 插件（索引名称 `idx_kh_chunk_content_trgm`）。

## 二、 高频故障错误码 (Error Codes) 与修复 SOP

### 2.1 错误码：`ERR_REDIS_CONN_TIMEOUT_504`
* **现象描述**：Agent 无法从 Redis 恢复短期对话记忆，导致会话上下文丢失。
* **排查路径**：
  1. 检查 Redis 连接池是否达到上限（默认 max 1000）；
  2. 检查密码配置中包含特殊字符时是否进行了 URL Encode 编码；
  3. 执行 `redis-cli ping` 验证延迟。
* **应急修复**：执行 `systemctl restart redis-sentinel` 强制触发哨兵主从切换。

### 2.2 错误码：`ERR_RERANK_API_UNAUTHORIZED_401`
* **现象描述**：检索阶段调用通义千问 `gte-rerank` 重排 API 返回 401 Unauthorized。
* **根因分析**：环境变量 `ALIYUN_API_KEY` 或 `OPENAI_API_KEY` 过期、被撤销或拼写错误。
* **兜底效果**：系统会自动触发内置降级机制，跳过 `gte-rerank` 精排，降级取候选池 Top 4，服务不会中断。

### 2.3 错误码：`ERR_PG_VECTOR_DIM_MISMATCH_409`
* **现象描述**：执行向量近邻检索时报错 `different vector dimensions 1536 and 1024`。
* **解决方案**：确保 Embedding 模型输出维度统一设为 1024（代码入参指定 `VECTOR_DIM = 1024`）。
