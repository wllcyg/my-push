# 2026年二季度各部门业绩与运营报告

> **报告发布**：集团战略财务部  
> **数据范围**：2026年04月01日 至 2026年06月30日  

---

## 一、 整体营收与部门贡献概览

二季度集团实现总营收 8,500 万元，同比增长 28.5%。各核心业务部门营收贡献如下：

* **云原生基础设施部**：营收 3,200 万元，占总营收 37.6%，同比增长 35%。
* **AI 与智能应用部**：营收 2,800 万元，占总营收 32.9%，同比增长 42%（增速第一）。
* **企业数字化咨询部**：营收 1,500 万元，占总营收 17.6%，同比增长 12%。
* **安全与合规服务部**：营收 1,000 万元，占总营收 11.9%，同比增长 18%。
